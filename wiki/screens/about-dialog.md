# About Dialog

## What it does
Opened from the info icon in the custom title bar. Shows the app icon, name and running version, a one-line description, a 3-step "How to use", an update check against the latest GitHub release (with a Download button when a newer version exists), and links to GitHub, All releases and Report an issue.

## Key files
- `src/main/kotlin/about_screen/AboutDialog.kt` — the Compose `Dialog`: header, how-to steps, `UpdateBox` (Checking / UpToDate / Available / Failed), link row, Close
- `src/main/kotlin/about_screen/AboutViewModel.kt` — `currentVersion` (from `BuildInfo.VERSION`), `updateState: StateFlow<UpdateState>`, `checkForUpdates()`, `downloadUrl(release)`, repo/releases/issues URLs
- `src/main/kotlin/data/util/UpdateChecker.kt` — `fetchLatest()` calls `api.github.com/repos/itxaliraza/Localizer/releases/latest` via `NetworkClient` and parses `tag_name`, `html_url` and the first `.exe` asset; `isNewer(latest, current)` compares `MAJOR.MINOR.PATCH` numerically (leading `v` allowed, missing parts = 0)
- `src/main/kotlin/domain/model/LatestRelease.kt` — `LatestRelease(version, pageUrl, installerUrl?)`
- `src/main/kotlin/common_components/OpenUrl.kt` — `openUrl(url)` via `java.awt.Desktop.browse`
- `build/generated/buildinfo/buildinfo/BuildInfo.kt` — generated by the `generateBuildInfo` Gradle task (see [infra/build.md](../infra/build.md)); holds `VERSION`

## State & data
- **State holder:** `AboutViewModel` (plain class, own `CoroutineScope(SupervisorJob() + Dispatchers.IO)`)
- **State:** `UpdateState` sealed interface — `Idle`, `Checking`, `UpToDate(latestVersion)`, `Available(release)`, `Failed(message)`
- **Reads:** GitHub REST API (one unauthenticated request per check; GitHub allows 60/hour per IP)
- **Dialog visibility:** `showAbout` local `mutableStateOf` in `CustomTitleBar` (`Main.kt`)

## Dependencies
- `AboutViewModel` via Koin `factory`, obtained with `koinInject()` in `CustomTitleBar`
- `NetworkClient`, kotlinx.serialization `Json` (in `UpdateChecker`)
- Common components: `PillButton`, `PillStyle`, `AppIcons.OpenInNew`, `HorizontalSpacer`, `VerticalSpacer`, `openUrl`

## Consumers
- `src/main/kotlin/Main.kt` — `CustomTitleBar` injects `AboutViewModel`; info icon sets `showAbout = true`; renders `AboutDialog`
- `src/main/kotlin/di/SharedModule.kt` — `factory { AboutViewModel() }`

## Notes
- The update check starts automatically the first time the dialog opens (`LaunchedEffect` when state is `Idle`); the result is kept for later openings because `koinInject()` is remembered for the title bar's lifetime. "Check again" / "Retry" re-run it.
- **Download** opens the `.exe` asset URL directly (the browser downloads it); if the release has no `.exe`, it opens the release page.
- Local builds report the fallback version from `build.gradle.kts` (currently `9.0.3`), not the tag, unless run with `-PappVersion=…`.
- `LatestRelease` lives in `domain/model/` so the UI doesn't import from `data/`.
